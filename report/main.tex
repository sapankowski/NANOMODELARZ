\section{Introduction}

This project studies bulk nickel (Ni) and nickel oxide (NiO) using periodic
density-functional-theory calculations in VASP.  The starting crystal
structures were taken from the Materials Project database
\cite{materials-project}.  The Ni structure corresponds to the fcc Ni entry
\texttt{mp-23}, while the NiO structure was based on the rocksalt NiO entry
\texttt{mp-19009} \cite{mp-ni,mp-nio}.

All calculations used periodic boundary conditions and bulk simulation cells;
no surfaces, vacancies, defects, or finite-temperature molecular dynamics were
included.  For Ni, the simulation cell was the conventional fcc cubic cell with
four Ni atoms.  The starting lattice parameter was approximately
\(a = 3.475~\mathrm{\AA}\), and the fractional atomic positions were
\((0,0,0)\), \((0,\frac{1}{2},\frac{1}{2})\),
\((\frac{1}{2},0,\frac{1}{2})\), and
\((\frac{1}{2},\frac{1}{2},0)\).

For NiO, the underlying crystal structure was rocksalt.  Because NiO is
antiferromagnetic, we used a magnetic AFM-II cell rather than the smallest
non-magnetic rocksalt primitive cell.  The cell contains two Ni atoms and two O
atoms.  The two Ni atoms are placed on alternating \([111]\) planes and assigned
opposite initial magnetic moments, which allows the AFM-II ordering to be
represented explicitly.  This magnetic setup is consistent with the VASP NiO
magnetism tutorial and with the known AFM-II ordering of bulk NiO
\cite{vasp-nio-magnetism}.

All input files, Slurm submission scripts, post-processing scripts, processed
tables, and report figures used in this work are provided in the project Git
repository: \url{git@github.com:sapankowski/NANOMODELARZ.git}
(\url{https://github.com/sapankowski/NANOMODELARZ}).  The
\texttt{submission\_inputs} directory contains a compact, task-organized copy
of the VASP inputs and scripts for reproducibility, while the tracked
\texttt{outputs} and \texttt{report/figures} directories contain the processed
CSV/Markdown tables and plotted figures used in the report.  Very large raw
VASP artifacts such as \texttt{WAVECAR}, \texttt{CHGCAR}, full
\texttt{vasprun.xml}/\texttt{vaspout.h5} files, and large raw \texttt{OUTCAR}
files are not included in the repository because the complete raw
\texttt{outputs} tree is several gigabytes and contains files above the GitHub
single-file size limit.
